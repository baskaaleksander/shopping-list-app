# Shopping List App

## Testing Instructions

To run the automated tests for this project, you can use the following commands:

### Running Tests

Run all unit and integration tests using Jest:
```bash
npm test
```

### Writing Tests

Tests are written using Jest and `@testing-library/react-native`. 
Test files are located in the `__tests__` directory and follow the `*.test.ts` or `*.test.tsx` naming convention.

When writing UI tests, prefer testing user interactions and accessible elements rather than implementation details.
